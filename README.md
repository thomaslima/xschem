
## About this fork
This is [thomaslima/xschem](https://github.com/thomaslima/xschem), an experimental fork that
adds a native macOS build (Aqua Tk, no XQuartz). Download a ready-to-run `Xschem.app` from
[Releases](https://github.com/thomaslima/xschem/releases) or install it with Homebrew
(`brew install thomaslima/tap/xschem-mac`); see [README_MacOS.md](README_MacOS.md), which also
explains how to open the downloaded app past Gatekeeper. Everything else is upstream xschem,
and the native macOS build is not supported by upstream.

## NOTICE
Xschem is now hosted also on [codeberg](https://codeberg.org/stef_xschem/xschem/).
All xschem repositories are exact mirrors, so choose the one that works best for you.

# xschem

A schematic editor for VLSI/Asic/Analog custom designs, netlist backends for VHDL, Spice and Verilog. The tool is focused on hierarchy and parametric designs, to maximize circuit reuse.

[Manual and instructions](http://repo.hu/projects/xschem/xschem_man/xschem_man.html)
